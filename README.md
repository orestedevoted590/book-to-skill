## 📖 How to Use the Application

The interface is simple. You select your book, define the skill name, and let the tool do the heavy lifting.

### Step 1: Select Your PDF
Click the button labeled "Select PDF" inside the application. Browse your folders to find the technical book you want to convert. The software reads the text and images to map out the concepts.

### Step 2: Name Your Skill
Give your skill a name. This name helps you find it later when you talk to Claude Code. If you are uploading a book on Python, name it something like "python-master-guide."

### Step 3: Run the Conversion
Click "Convert to Skill." The software creates a small file with all the book data. This process takes a few minutes depending on the size of your book.

## ❓ Frequently Asked Questions

**Does the software store my books online?**
No. Everything happens on your local machine. Your privacy remains intact.

**Can I use any PDF?**
Yes. However, the software works best with technical books that contain clear headers and structured chapters. Handwritten notes or scanned documents might produce lower-quality results.

**What do I do if the software freezes?**
Check if your PDF is very large. If the book is over 500 pages, the software needs a moment to process the data. Wait for one minute. If it remains stuck, close the app and restart it.

**Where does the tool save the output?**
The tool saves the skill file in a folder named "Skills" inside your user documents folder. You can point Claude Code to this path once you initialize your workspace.

## 💡 Tips for Success

- Use clean PDFs whenever possible.
- Keep your book titles short to make typing commands easier.
- Use the "Preview" feature to verify the text extraction before you run the conversion. 
- Ensure you possess the rights to the material you convert.

## 🧩 How it Works

The software uses a process called text extraction. It scans the PDF pages and identifies key topics, methods, and code blocks. It then packages this information into a JSON format. This format tells the AI assistant how to pull specific answers from your book when you ask a question. This turns a static document into an interactive reference guide.

## 🔒 Privacy and Security

Data security is a priority. This application does not track your activity or send your book contents to external servers. All operations occur on your personal computer. You control the files, and you decide which ones to process.
